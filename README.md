# ระบบตอบรับการประชุม

แบบตอบรับการประชุมที่ใช้ได้ทุกประชุมตลอดปี ผู้ดูแลเพิ่มประชุมใน Google Sheet แล้วได้ลิงก์ส่งไปกับหนังสือเชิญ

```
ผู้เข้าร่วม ──> หน้าเว็บ (Netlify) ──> Apps Script (เว็บแอป) ──> Google Sheet
                                              └──> อีเมลยืนยัน
```

| ส่วน | อยู่ที่ | หน้าที่ |
| --- | --- | --- |
| `public/index.html` | Netlify | หน้าแบบตอบรับสำหรับผู้เข้าร่วม |
| `public/admin.html` | Netlify (`/admin`) | หน้าผู้ดูแล: เพิ่ม/แก้ไขประชุม ตั้งค่าใช้จ่าย ดูยอดและรายชื่อ ดาวน์โหลด CSV แก้ตัวเลือก หน่วยงาน และค่าทั่วไป |
| `apps-script/Code.gs` | Apps Script ของ Google Sheet | API อ่านข้อมูลประชุม บันทึกคำตอบ ส่งอีเมลยืนยัน |
| Google Sheet | Google Drive | ฐานข้อมูล และหน้าตั้งค่าของผู้ดูแล |

## แท็บใน Google Sheet

| แท็บ | ใช้ทำอะไร |
| --- | --- |
| `meetings` | ทะเบียนประชุม 1 แถวต่อ 1 ประชุม: รหัส ชื่อ ประเภท วันที่ สถานที่ วันปิดรับ จำนวนรับ สถานะ ค่าใช้จ่าย ลิงก์ |
| `responses` | คำตอบทั้งหมด (ระบบเขียนเอง ห้ามแทรกหรือสลับคอลัมน์) |
| `summary` | ยอดต่อประชุม: On-site / Online / ไม่เข้าร่วม / ขอที่พัก / พักเดี่ยว / อาหารพิเศษ |
| `units` | รายชื่อหน่วยงานตั้งต้น ระบบรวมกับหน่วยงานที่เคยมีคนตอบมาแล้วให้อัตโนมัติ |
| `lists` | ตัวเลือกคำนำหน้า ตำแหน่ง ประเภทอาหาร การเดินทาง |
| `config` | ที่อยู่เว็บ เบอร์ติดต่อ ระยะเวลาเก็บข้อมูล PDPA (5 ปี) ชื่อผู้ส่งอีเมล |

## กติกาที่ระบบใช้

- **ลิงก์ต่อประชุม:** `https://<เว็บ>/m/<รหัสประชุม>` ออกจากหน้าผู้ดูแลด้วยปุ่ม **ออกลิงก์** (คอลัมน์ `link` ใน Sheet ก็สร้างให้เช่นกัน ลิงก์แบบเดิม `?m=<รหัส>` ยังใช้ได้)
- **รหัสประชุม:** ระบบออกให้อัตโนมัติตอนบันทึกประชุมใหม่ เรียงต่อกัน `HIA001`, `HIA002`, … (ต่อจากเลขสูงสุดที่มี) แก้รหัสภายหลังไม่ได้ เปลี่ยนตัวอักษรนำหน้าได้ที่แท็บ **ตั้งค่าทั่วไป** (`meeting_id_prefix`)
- **ปิดรับ:** สถานะ = ปิด หรือเลยวันปิดรับ
- **รูปแบบการเข้าร่วม (`attend_mode`):** ผู้ดูแลเลือกต่อประชุม
  - `hybrid` On-site และ Online (ค่าเริ่มต้นของประชุมทั่วไป)
  - `onsite` On-site อย่างเดียว (ค่าเริ่มต้นของประชุมเชิงปฏิบัติการ)
  - `online` Online อย่างเดียว
- **ที่นั่ง (`capacity`):** นับเฉพาะ On-site เว้นว่าง = ไม่จำกัด หัวฟอร์มแสดงจำนวนที่เหลือ เมื่อเต็มแล้ว
  - ประชุม On-site และ Online: ตัวเลือก On-site ขึ้น "เต็มแล้ว" ยังเลือก Online หรือไม่เข้าร่วมได้
  - ประชุม On-site อย่างเดียว: ขึ้นหน้า "ขออภัย ที่นั่งเต็มแล้ว" พร้อมปุ่มให้คนที่ลงทะเบียนไว้แจ้งยกเลิก
  - ระบบตรวจซ้ำตอนกดส่ง กันหลายคนส่งพร้อมกันตอนเหลือที่สุดท้าย คนที่ลงทะเบียนไว้แล้วแก้ข้อมูลตัวเองได้เสมอ
- **หน้าที่พัก:** แสดงเมื่อเป็น workshop, เข้าร่วม On-site, หน่วยงานอยู่จังหวัดอื่นที่ไม่ใช่กรุงเทพมหานคร (รวมปริมณฑล) และค่าที่พักไม่ได้ตั้งเป็น "ไม่มี"
- **ห้องพัก:** พักคู่ หรือพักเดี่ยว (เงื่อนไขค่าห้องพักเดี่ยวเขียนไว้ในหมายเหตุค่าใช้จ่าย `pay_note` ของแต่ละประชุม)
- **ค่าใช้จ่าย:** ผู้ดูแลตั้งค่าอาหาร ค่าที่พัก ค่าเดินทาง เป็น ผู้จัดรับผิดชอบ / เบิกจากต้นสังกัด / ไม่มี ผู้เข้าร่วมต้องติ๊กรับทราบก่อนส่ง และเงื่อนไขนี้แสดงซ้ำในอีเมลยืนยัน
- **ข้อมูลประชุมออนไลน์:** ผู้ดูแลกรอกชื่อระบบ ลิงก์ User/Meeting ID และ Password/Passcode ต่อประชุม ข้อมูลนี้**ไม่แสดงในแบบตอบรับ** ส่งทางอีเมลยืนยันเฉพาะผู้ที่เลือก Online ถ้ายังไม่มีลิงก์ตอนผู้เข้าร่วมลงทะเบียน อีเมลจะแจ้งว่าผู้จัดจะส่งให้ภายหลัง แล้วผู้ดูแลกด **ส่งข้อมูลประชุมออนไลน์ทางอีเมล** ในหน้ารายชื่อ เพื่อส่งให้ผู้ลงทะเบียน Online ทุกคนในครั้งเดียว (ใช้ส่งซ้ำได้เมื่อเปลี่ยนลิงก์)
- **ตอบซ้ำ:** อีเมลเดิม + ประชุมเดิม = แก้ไขแถวเดิม (ใช้ข้อมูลล่าสุด) ใช้แก้ไขหรือยกเลิกได้
- **PDPA:** ลบคำตอบของประชุมที่จบเกิน 5 ปีด้วยฟังก์ชัน `purgeExpiredResponses`

## ติดตั้งครั้งแรก

### 1. Google Sheet + Apps Script

1. สร้าง Google Sheet ใหม่ (ใช้บัญชีของหน่วยงาน อีเมลยืนยันจะส่งจากบัญชีนี้)
2. เมนู **ส่วนขยาย → Apps Script** ลบโค้ดเดิม แล้ววางเนื้อหา `apps-script/Code.gs`
3. ที่ **การตั้งค่าโปรเจ็กต์** ติ๊ก "แสดงไฟล์ appsscript.json" แล้ววางเนื้อหา `apps-script/appsscript.json`
4. เลือกฟังก์ชัน `setup` แล้วกด **เรียกใช้** (อนุญาตสิทธิ์ครั้งแรก) จะได้แท็บครบ (แท็บ `meetings` ว่าง, หน่วยงานกรมอนามัย 37 แห่ง + สสจ. 76 จังหวัด, ตัวเลือกตั้งต้น) และได้**รหัสผู้ดูแล**ในบันทึกการดำเนินการ (ดูอีกครั้งได้ด้วยฟังก์ชัน `showAdminKey` หรือเปลี่ยนเองที่ การตั้งค่าโปรเจ็กต์ → คุณสมบัติของสคริปต์ → `ADMIN_KEY`)
5. เรียกใช้ `authorizeMail` หนึ่งครั้ง เพื่ออนุญาตการส่งอีเมล
6. **การทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่ → เว็บแอป**
   ดำเนินการในฐานะ "ฉัน" · ผู้ที่มีสิทธิ์เข้าถึง "ทุกคน" → คัดลอก URL ที่ลงท้ายด้วย `/exec`
7. (แนะนำ) **ทริกเกอร์ → เพิ่มทริกเกอร์** ให้ `purgeExpiredResponses` รันตามเวลา เดือนละครั้ง

### 2. Git + Netlify

1. ใส่ URL จากข้อ 1.6 ใน `public/config.js` ที่ `API_URL`
2. push repo นี้ขึ้น GitHub
3. Netlify → **Add new site → Import an existing project** → เลือก repo
   ไม่ต้องตั้ง build command (`netlify.toml` ระบุโฟลเดอร์ `public` ไว้แล้ว)
4. นำที่อยู่เว็บที่ได้ (เช่น `https://xxx.netlify.app/`) ไปใส่ในแท็บ `config` แถว `site_url`

### 3. ทดสอบ

ทดสอบโดยไม่ให้เลข HIA ถูกใช้ไป:

1. หน้าผู้ดูแล → **ตั้งค่าทั่วไป** → ตัวอักษรนำหน้ารหัสประชุม เปลี่ยนเป็น `TEST` → บันทึก
2. เพิ่มประชุมทดสอบ (ได้รหัส `TEST001`) แบบ On-site และ Online ใส่ลิงก์ออนไลน์ทดสอบ
3. เปิดลิงก์ที่ออกให้ กรอกด้วยอีเมลตัวเอง 2 ครั้ง (On-site และ Online) ตรวจว่าได้แถวใน `responses` และได้อีเมลยืนยัน ฉบับ Online ต้องมีลิงก์และรหัส
4. ลบแถวทดสอบในแท็บ `responses` แล้วลบประชุมทดสอบจากหน้าผู้ดูแล
5. เปลี่ยนตัวอักษรนำหน้ากลับเป็น `HIA` → ประชุมจริงแรกจะได้ `HIA001`

## ใช้งานประจำ

เปิด `https://<เว็บ>/admin` แล้วใส่รหัสผู้ดูแล

1. แท็บ **การประชุม** → **+ เพิ่มการประชุม** กรอกชื่อ วันที่ สถานที่ วันปิดรับ และเงื่อนไขค่าใช้จ่าย
2. กดบันทึกแล้วระบบ**ออกลิงก์**ให้ทันที (หรือกด **ออกลิงก์** ของประชุมใดก็ได้ในตาราง) คัดลอกลิงก์ หรือคัดลอก**ข้อความสำเร็จรูป**ที่มีชื่อประชุม วันที่ วันปิดรับ และลิงก์ ไปวางในหนังสือเชิญ
3. ดูยอดในตาราง กด **รายชื่อ** เพื่อดูผู้ตอบรับ และ **ดาวน์โหลด CSV** (เปิดใน Excel ได้ ภาษาไทยไม่เพี้ยน)
4. ปิดรับก่อนกำหนดได้ด้วยการแก้สถานะเป็น "ปิดรับ" ลบประชุมได้เฉพาะที่ยังไม่มีผู้ตอบ

ทุกอย่างที่แก้ในหน้าผู้ดูแลจะบันทึกลง Google Sheet จึงยังเปิดดูหรือแก้ใน Sheet ตรงได้เหมือนเดิม

รหัสผู้ดูแลจำไว้ในแท็บเบราว์เซอร์จนกว่าจะปิดแท็บหรือกดออกจากระบบ ถ้าใส่รหัสผิด 10 ครั้ง ระบบจะล็อก 15 นาที

## ข้อควรรู้

- **โควตาอีเมล** ของ Apps Script: บัญชี Gmail ทั่วไปประมาณ 100 ฉบับ/วัน, Google Workspace ประมาณ 1,500 ฉบับ/วัน ถ้าเกิน ระบบยังบันทึกคำตอบ แต่จะแจ้งผู้ตอบว่าส่งอีเมลไม่สำเร็จ
- **แก้ `Code.gs` แล้ว** ให้ไปที่ การทำให้ใช้งานได้ → จัดการ → แก้ไข → เวอร์ชันใหม่ เพื่อให้ URL เดิมใช้โค้ดใหม่ (ถ้าสร้างการทำให้ใช้งานได้รายการใหม่ URL จะเปลี่ยน)
- **รายชื่อหน่วยงานตั้งต้น** ในแท็บ `units` เป็นชุดเริ่มต้น ควรตรวจและเติมชื่อสำนัก/กองให้ครบ
